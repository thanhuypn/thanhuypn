### 📌 Giới thiệu dự án

**Hệ thống quản lý kinh doanh ô tô điện** là bài tập nhóm nhằm xây dựng một hệ thống hỗ trợ quản lý hoạt động kinh doanh và bán hàng ô tô điện.

Dự án tập trung vào việc số hóa quy trình quản lý, tối ưu hóa dữ liệu và nâng cao hiệu quả hoạt động kinh doanh.

### ⚙️ Các chức năng chính

| Chức năng | Mô tả |
|:---|:---|
| 🚗 Quản lý ô tô điện | Quản lý thông tin xe, hãng xe, mẫu xe và giá bán |
| 👥 Quản lý khách hàng | Lưu trữ và cập nhật thông tin khách hàng |
| 🛒 Quản lý bán hàng | Quản lý đơn hàng và giao dịch mua bán |
| 📦 Quản lý kho | Theo dõi số lượng xe và tình trạng tồn kho |
| 📊 Thống kê & báo cáo | Thống kê doanh thu và tình hình kinh doanh |

### 🎯 Mục tiêu dự án

- Xây dựng hệ thống quản lý kinh doanh hiệu quả.
